Note de synthèse — Spelc

Système de suivi des élections professionnelles CCM — Spelc

Outil interne du Spelc pour le suivi des élections professionnelles 2026 : scrutin national CCMMEP et scrutins académiques locaux — participation, adhérents, relances et simulation de la journée des PSA.

3rôles utilisateurs
41Spelcs
32académies
8jours de scrutin (3 → 10 déc.)

Vue d'ensemble

Une plateforme, trois profils, un seul socle

L'application couvre le cycle complet du scrutin : import quotidien des fichiers d'émargement JSON, tableaux de bord de participation (national, académique, par Spelc), gestion des adhérents, et relances mail/SMS via Brevo — y compris pour les Présidents de Section (PSA) simulés avant le jour J. Trois profils d'administrateurs se partagent ces fonctions selon leur périmètre.

Fonctionnalités

Par profil d'administrateur

Chaque rôle a accès uniquement aux données et actions de son périmètre.

Admin général

Pilotage national

Import CCMMEP national

Import du fichier JSON quotidien du scrutin national (émargements cumulés).

Gestion des comptes

Création manuelle ou import en masse (CSV/Excel) des comptes admin académique et admin Spelc.

Gestion des adhérents

Import global par Spelc, ou import/suppression de tous les adhérents en un clic.

Simulation & relances PSA

Simulation de la journée des PSA, relance mail/SMS des non-votants — une seule relance par personne et par canal.

Récupération automatique

Scraping headless (Playwright) du portail national pour récupérer le fichier CCMMEP.

Journal des relances

Historique consultable de chaque envoi (mail/SMS, campagne, destinataire, succès).

Admin académique

Pilotage local

Imports 1er / 2nd degré

Import des fichiers JSON de son académie (deux fichiers distincts).

Tableaux de bord académiques

Scrutin local et scrutin national filtré sur l'académie.

Récupération automatique

Scraping headless des deux fichiers académiques (1D et 2D).

Filtre votant / non-votant

Sur les tableaux de scrutin, pour cibler rapidement les non-votants.

Admin Spelc

Adhérents & relances

Import des adhérents

Liste des adhérents du Spelc, au format CSV ou Excel.

Configuration Brevo

Clé API et modèles de mail/SMS propres au Spelc.

Campagnes de relance

Envois réels aux non-votants, avec un mode test dédié.

Suivi & tableau de bord

Statistiques d'envoi et participation de son Spelc.

Documents

Arborescence partagée

Dépôt par l'admin général

Dossiers et documents de tout type (PDF, Word, Excel, images...), organisés en arborescence — une seule copie physique en base, jamais dupliquée par académie.

Lecture seule pour les académies

Chaque académie consulte et télécharge la même arborescence — mêmes lignes en base, pas de copie — sans possibilité de dépôt ni de suppression, toujours à jour sans synchronisation.

Transverse & sécurité

Socle commun

Authentification par rôle

Connexion JWT, changement de mot de passe obligatoire à la première connexion.

Secrets chiffrés

Mots de passe des portails de scraping chiffrés en base (AES-256-GCM), jamais renvoyés en clair.

Imports robustes

Parseur CSV/Excel (exceljs) avec validation ligne par ligne des imports en masse.

Traçabilité

Journal NDJSON de tous les envois mail/SMS, consultable côté admin général.

Assistant IA

Function calling (Mistral)

Admin général — CCMMEP

Accès à toutes les données : scrutin national, toutes les académies, tous les Spelcs (adhérents compris).

Admin académique

Uniquement les données de sa propre académie (national filtré + scrutin local) — jamais les autres académies ni les adhérents.

Admin Spelc

Uniquement les données de son propre Spelc, adhérents et non-adhérents — jamais un autre Spelc.

Pas d'hallucination possible

Le modèle choisit parmi des outils prédéfinis basés sur les mêmes requêtes que les tableaux de bord ; le périmètre est forcé côté serveur, jamais confié au modèle.

Note technique

Schéma de la base de données

Base SQLite (via better-sqlite3), pas PostgreSQL — un seul fichier, monté dans le volume Docker persistant. 20 tables réparties en six domaines ; les rapprochements par spelc/academie sont de simples colonnes texte, pas des clés étrangères.
